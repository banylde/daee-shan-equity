# 五绝归山 · 大鹅基金·山部股权投资看板

“红利为基、质量为核、估值为尺”的A股+港股通高股息选股研究工具：纯静态页面 + GitHub Actions 抓数。
**仅为个人研究工具，不构成投资建议。** 仓库内无任何持仓/账户/收益数据，也无任何密钥。

- `config.json`：股票池、七维权重、指标分界、红线/分层门槛（**默认参数，待鹅哥确认**）
- `scripts/fetch_fin.py`：每周六抓东方财富财务、分红、估值历史 → `data/fin.json`
- `scripts/build.py`：每个交易日抓腾讯行情/K线与东方财富当日估值，打分 → `data/latest.json`
- 权重与门槛为待回测参数；高分不等于买入信号。

## 纸面成交约定

与大鹅基金其他看板一致：信号在信号日收盘后计算，成交按下一交易日开盘价（T+1 open）。本股权看板不模拟涨跌停无法成交（没有“涨停买不到、跌停卖不出”的顺延规则）。页面顶部有同样的短注。不在这里写回测收益。

## 行情源与数据过期

- 主源：腾讯行情 `qt.gtimg.cn`、腾讯前复权日K `web.ifzq.gtimg.cn`。20日均成交额＝近20根K线的收盘×成交量（A股成交量按手×100，港股按股）。
- 备用：东方财富 `push2` 行情、`push2his` 日K成交额。只在主源失败，或K线没有可用成交量时使用；备用成交额用接口给出的成交额，不把缺失填成0。
- 20日均成交额缺失只记「数据缺失」，不写入流动性否决，也不因此把名字移出五绝。低于门槛的真实成交额仍按原门槛处理。
- 最近A股交易日取上证指数日期（主源失败再用东方财富日K）。`data/latest.json` 的 `data_stale` 在行情日期落后于该交易日时为 true，页面显示「数据过期」。主源和备用都失败时沿用上次已抓到的结果并打上这个标记，不编造报价。

## 调仓记录

`data/history.json` 在每次正式调仓时追加一条：日期、调入/调出（代码+名称）、权重、变动说明。页面「调仓记录」读取该文件。已写入的只有仓库里真实发生过的调仓。
