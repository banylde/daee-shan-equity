# 五绝归山 · 大鹅基金·山部股权投资看板

“红利为基、质量为核、估值为尺”的A股+港股通高股息选股研究工具：纯静态页面 + GitHub Actions 抓数。
**仅为个人研究工具，不构成投资建议。** 仓库内无任何持仓/账户/收益数据，也无任何密钥。

- `config.json`：股票池、七维权重、指标分界、红线/分层门槛（**默认参数，待鹅哥确认**）
- `scripts/fetch_fin.py`：每周六抓东方财富财务、分红、估值历史 → `data/fin.json`
- `scripts/build.py`：每个交易日抓腾讯行情/K线与东方财富当日估值，打分 → `data/latest.json`
- 权重与门槛为待回测参数；高分不等于买入信号。
